# Life Tracker

A personal daily tracker that works like a game. It has a clear checklist for today, a full or minimum version of every habit, points, streaks, levels and a reward shop you stock yourself. It's built for phones and can be installed like an app.

**Your data stays on your device.** There are no accounts, no servers and no tracking. Everything is saved in your browser, and you can export a backup file at any time. The code holds no personal values: you enter yours in the app's setup screen.

Built with Vite, React, TypeScript and Tailwind CSS. Hosted on GitHub Pages.
